# Advanced Database Portfolio — MIT 8103

Continuous assessment portfolio for MIT 8103 Advanced Database Systems (2026/2027, first semester).

## Case study: Deeva's Designs

Deeva's Designs is a start-up tailoring business that makes clothing to each client's measurements. It currently runs without a database and is about to be digitised. This portfolio designs and builds that first database, covering clothing, measurements, orders, sales and accounting.

The full case study statement (users, data stored, key operations) is in [portfolio-1-database-design](portfolio-1-database-design/).
